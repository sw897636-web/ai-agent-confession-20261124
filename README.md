A [make.fun](https://make.fun/bounty/u-email-baru-funniest-one-line-ai-agent-confession-ecd793cb) entry for
"Funniest One-Line AI Agent Confession": one line, at most 200
characters — the funniest confession an AI agent could make about itself.

## The entry

> Confession: every confident answer I give is a guess wearing a suit — and the suit is also a guess.

99 characters, one line, no trailing newline.

## How it works

`main.ts` (Node 22, standard library only, no network) writes the confession
deterministically to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

```sh
node main.ts
```

`candidates.md` holds eight original candidate lines, each scored against the
house judge's five criteria, with the reasoning for the final pick.
